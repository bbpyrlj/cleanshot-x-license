## CleanShot X 是干什么的，哪些人其实不用买

- 录屏时同时录麦克风和摄像头，讲解能把自己放进画面

- 截完直接上传，拿一条链接发出去，不用先存桌面再翻出来

- OCR，把截图里的文字提出来变成可复制的文本

- Quick Access，最近截的图在屏幕角落挂着，拖进聊天窗口就行

用得上的场景很集中：写文档配图、录教程、给同事描述一个 bug 出现在哪个角落、做产品演示、给客户发带标注的截图。这些事一周干三次以上，省下来的时间是有感觉的。

## 用久了会觉得值的功能，和几个真实的坑

值得的地方主要在细节。滚动截图是很多人买它的直接理由，长网页、长聊天记录、长代码文件一次截完，不用拼接。录屏时把键盘按键显示在画面上，教人用快捷键一遍就懂。OCR 在需要抄一段图里的文字时很好用。Quick Access 这个设计一开始不觉得，用惯之后截图找不到了反而会不习惯。

坑也得说：

**买断不等于永久更新。** 更新期过了，你手上的版本继续能用，但新版本要再付。买之前算一下自己是不是那种“有新版本就想升”的人，是的话把后续更新的成本也算进去。

**云上传和分享链接依赖它的服务。** 截完直接生成一条链接发出去，走的是它自家的云服务，这类服务通常有额度或者有效期限制，具体写在软件里。拿它当长期图床不合适，重要图片还是自己存一份。

**菜单栏会变挤。** 它是常驻菜单栏的工具，图标本来就多的桌面会更满，这个没法绕开。

**授权绑设备，换机前先反激活。** 设备授权换新 Mac 的时候，先在旧机器上把授权释放出来，再去新机器上激活，不然可能提示名额已满。页面写了激活次数的，按页面的规则来。

**系统自带功能越来越强。** macOS 自己的截图和录屏这几年补了不少，轻度用户花钱的动力确实不足。这不是它的问题，是你需求的问题。
